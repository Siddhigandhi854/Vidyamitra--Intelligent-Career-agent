## VidyāMitra – The Intelligent Career Agent

VidyāMitra is an AI-powered resume evaluator, career trainer, and personalized career planner.  
This repository contains a **FastAPI** backend and a **React + Vite** frontend that are fully decoupled and communicate only over HTTP APIs.

### Structure

- **backend/**: FastAPI application, routers, and services  
- **web/**: React + Vite SPA with routing, dashboards, and interactive modules

### Tech Stack

- **Backend**: Python 3.10+, FastAPI, Uvicorn, Pydantic, python-dotenv, JWT auth, NLTK  
- **Frontend**: Node.js 18+, React, Vite, Axios, React Router

For a hands-on guide to installation and running the project, see `QUICK_START.md`.
